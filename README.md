# Computer vision-based yield loss assessment
## Based on Picture-Based Insurance by Harold Achicanoy-Estrella
## WUR & ABC, 2025

The `cv_pbi` repository has the different tested models to predict yield losses in maize by using pictures in farmer-managed fields and the Day Of the Year (DOY) as a predictor variable. Our response variable is categorical with the following categories:
- None: zero loss indicated by crop experts
- Low damage: 10-20% loss
- Medium damage: 30-50% loss
- High damage: >50% loss
