# Computer vision-based crop loss assessment for smallholder agriculture
## Based on Picture-Based Insurance
## Author: Harold Achicanoy-Estrella
## WUR & ABC, 2025

The `cv_pbi` repository has the different tested models to predict yield losses in maize by using pictures in farmer-managed fields and the numerical predictors: _day of the year_ (DOY) and the _number of days after sowing date_ (DAS). Our response variable is categorical with the following categories:
- Minor losses: 0-33% loss
- Moderate losses: 33-66% loss
- Large losses: 66-100% loss
